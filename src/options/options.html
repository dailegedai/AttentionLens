AttentionLens

AI settings

AttentionLens works fully offline with local rules. Add your own DeepSeek API key to enable semantic headline analysis, block classification, and natural-language explanations. The key is stored only in this browser profile and is used only by the background worker.

API key

Get a key from platform.deepseek.com → API keys. It is stored in chrome.storage.local and is never sent to any server except the configured API endpoint.

Endpoint

Use the model id enabled for your account. A custom base URL on another host also needs to be added to host_permissions in manifest.json.
